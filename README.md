# Semantic Event Hub

A simple event hub web page built with **HTML5 Semantic Elements** as part of the **freeCodeCamp Responsive Web Design** curriculum.

##  About

This project demonstrates how to build a well-structured web page using semantic HTML. It includes navigation, upcoming events, and past events with images while following accessibility and SEO best practices.

##  Features

* Semantic HTML5 structure
* Header and navigation menu
* Upcoming events section
* Past events section
* Event images with descriptive alt text
* Internal page navigation
* Clean and organized layout

##  Technologies Used

* HTML5

##  What I Learned

While building this project, I practiced:

* Using semantic HTML elements
* Creating accessible page structures
* Linking sections with anchor links
* Organizing content using articles and sections
* Writing cleaner and more meaningful HTML
